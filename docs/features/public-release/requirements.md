# Codex for ZCode 公开预览版

Status: Confirmed

## Goal

让已有 ChatGPT / Codex 账号、希望沿用 ZCode 中文工作台的用户，能够从公开源码构建本地客户端，完成会话、工具、审批和历史迁移。

## User Scenarios

1. 新安装用户读取自己账号的真实模型列表，选择模型并用订阅身份执行任务。
2. 用户导入自己的 Desktop 历史为独立副本，再继续工作。
3. 开发者能理解上游归属、构建条件、已验证范围，并报告问题或贡献。

## Scope

### In

- 公开独立派生仓库，保留 ZCode Apache-2.0 许可和上游归属。
- 中文优先、英文入口、构建指南、功能边界、路线图与贡献入口。
- 账号真实模型列表、可选显示别名；不携带个人固定型号或默认别名。
- 去除个人材料、会话、认证、测试日志与本机目录。

### Out

- 网络代理、账号转售、额度提升或区域可用性改变。
- Windows/Linux、远程 Codex、Desktop 专属连接器的完成声明。
- 本轮发布已公证二进制或承诺 Star 数量。

## Constraints

- 保留自用安装及源目录；公开代码在独立派生目录维护。
- 只发送经审查的源码和合成示例，不上传私有工作区或登录数据。
- 执行和审批仍由 Codex App Server 负责。

## Acceptance Criteria

- AC-001: 公开提交不含自用目录、会话快照、凭据、机器构建缓存或内部验收正文；上传清单和扫描可核验。
- AC-002: 新用户可见账号返回的真实模型，别名默认空；选择使用真实 ID，指定模型缺失时不悄悄切换；偏好保留草稿与任务选择。
- AC-003: README 给出定位、平台和版本、构建步骤、上游许可、边界与贡献入口；不把自用版验收当作公开版全平台验收。
- AC-004: 发布后 GitHub 仓库公开可读，默认分支包含本次提交，简介、主题和预览发行说明与源码一致。

## Decisions

- 使用 codex-for-zcode 名称；发布为源码 alpha，完整可安装发行版另行验收。
- 原有 ChatPromptEditor/菜单复用；仅放开模型列表，不重设计页面。公开版应用名 Codex for ZCode、独立标识和数据目录，与自用版并存。
- 模型选择由 CodexUiStore 保存默认值，ChatPane 持有当前会话待发送选择；服务只接收真实 ID。历史不会因改名而重写。
- 构建时从显式路径或 npm 全局安装定位固定版本 Codex，不复制凭据。
