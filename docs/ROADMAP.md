# Roadmap

路线图表达优先方向，不承诺时间或已经实现。

## 已有基础

- 本地 Codex App Server 会话、执行、审批与恢复。
- 原生复制 / 兼容续聊两种历史导入。
- 中文 ZCode 界面、项目归组、原生输入与可选模型别名。

## 下一个可交付版本

1. 用干净环境核验完整安装路径，补合成示例的真实操作短视频。
2. 增加 App Server 版本兼容测试，完善公开 CI。
3. 制作明确版本、校验和与签名状态的 macOS 发行包。

## 需要独立设计和贡献

- Windows / Linux 运行时定位、打包和端到端验证。
- 长历史的增量读取与首次加载性能。
- 远程 Codex 的身份、会话归属、断线恢复和审批。
- Desktop 专属能力逐项适配，不能仅把按钮复制过来。

Star 表达关注；复现步骤、真实测试和代码贡献决定这些方向能否落地。
