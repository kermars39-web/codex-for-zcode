# Roadmap

路线图表达优先方向，不承诺时间或已经实现。

## 已有基础

- 本地 Codex App Server 会话、执行、审批与恢复。
- 原生复制 / 兼容续聊两种历史导入。
- 中文 ZCode 界面、项目归组、原生输入与可选模型别名。
- Mac ARM64 ZIP 与 Windows x64 安装器预览，原生 runner 构建与校验和。

## 下一个可交付版本

1. 外部用户验证真实账号下的完整安装、执行与历史导入，补合成示例的真实操作短视频。
2. 增加 App Server 版本兼容测试，完善公开 CI。
3. 完成发行商签名、公证和更多真实 Windows 使用验证。

## 需要独立设计和贡献

- Intel Mac、Windows ARM / Linux 的打包和端到端验证。
- 长历史的增量读取与首次加载性能。
- 远程 Codex 的身份、会话归属、断线恢复和审批。
- Desktop 专属能力逐项适配，不能仅把按钮复制过来。

Star 表达关注；复现步骤、真实测试和代码贡献决定这些方向能否落地。
