# v0.1.0-alpha.1 — Codex for ZCode

首次公开源码预览：在 ZCode 中文工作台中连接本地 Codex App Server，使用自己的 ChatGPT 登录，处理任务、工具执行、文件修改和审批。

包含独立历史导入（原生复制 / 兼容续聊）、原版风格聊天区、草稿恢复和可选模型别名。公开默认按账号实际模型列表选择，不预设某个模型或别名。

- 源码构建目标：Apple Silicon macOS。
- 基线：ZCode 3.14.0，Codex CLI 0.155.1。
- 当前不附安装包；不承诺跨平台、远程 Codex 或 Desktop 专属工具支持。
- 不包含账号、私人历史或模型权限；不提供网络代理。

从 README 的构建步骤开始。欢迎带脱敏复现步骤的反馈与贡献。
